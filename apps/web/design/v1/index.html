Design reference / v1 / MUI v9.0.1

Desktop and mobile correction flows built as an evidence-first workbench.

The screens follow the Part 2 frontend brief: light and dark precision workspaces, strong evidence linkage, persistent validation surfaces, and MVP-sized auth, inbox, and correction-session flows. Each screen ships in a light and dark variant — desktop and mobile — as separate HTML files.

Direction Tech / utility palette — light and dark. Both use the same token system with inverted surface and text tokens.
Auth behavior Empty, invalid, and valid states are interactive through real field validation and seeded sign-in logic.
Workspace posture Split-pane review with low-confidence prioritization, provenance, and persistent validation status.
